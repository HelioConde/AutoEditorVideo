Antes de reutilizar uma decisão, verifique se suas entradas, versão do código ou critérios mudaram. Ao concluir trabalho relevante, atualize apenas o tópico afetado com decisão, evidência reproduzível, revisão, testes e pendência real. Revise estados operacionais no registro correspondente. Registre conhecimento reutilizável sem mídias privadas, credenciais, dados de contas ou raciocínio interno.
