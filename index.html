Projeto open source · Windows + Python

Arquivo Otaku.

Da ideia ao YouTube: radar editorial, roteiro, ilustrações de anime via IA, edição de Shorts, miniaturas e publicação OAuth. Execute no seu computador e mantenha a revisão criativa nas suas mãos.

Ver código e instalar no GitHub

Radar editorial

Ideias de anime, pauta, gancho e verificação do roteiro.

Gerador de cenas

Integração local com Codex Proxy, respeitando disponibilidade e cotas.

Edição vertical

MoneyPrinterTurbo, FFmpeg, narração e legendas.

Publicação YouTube

Miniaturas, título, descrição e autorização oficial OAuth.

Comece no PowerShell

git clone https://github.com/HelioConde/AutoEditorVideo.git
cd AutoEditorVideo
.\radar-conteudo.ps1

Antes de usar o radar, instale Python e dependências seguindo o README. O GitHub Pages é uma vitrine estática: não gera vídeos nem recebe credenciais.
